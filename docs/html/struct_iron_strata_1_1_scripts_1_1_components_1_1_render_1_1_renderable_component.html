Detailed Description

Represents a visual component that can be rendered within the scene.

The RenderableComponent struct is primarily used by systems to visually represent entities in the game world. It contains references to a 3D node, a mesh for the model, a customizable tint color, and an optional label for display purposes. This component is commonly used in conjunction with systems like RenderSystem and WagonHealthUISystem to manage and update the visual state of entities.
