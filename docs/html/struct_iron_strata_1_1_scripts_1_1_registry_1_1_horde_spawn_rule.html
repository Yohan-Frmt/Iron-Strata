Detailed Description

Defines a spawn rule for enemy generation during a horde event.

Rules are used by the spawn system to determine the composition of an enemy wave.

Parameters
typeThe type of enemy to spawn.
countThe number of individuals of this type to generate.
chanceThe probability (between 0 and 1) that this rule is applied.

readonly float IronStrata.Scripts.Registry.HordeSpawnRule.Chance = chance

Represents the probability of applying a specific spawn rule during a horde event.

The value ranges between 0.0 and 1.0, where 0.0 indicates the rule is never applied, and 1.0 signifies the rule is always applied. This is used to randomize enemy composition for a more dynamic horde generation system.
