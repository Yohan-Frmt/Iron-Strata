Detailed Description

Represents a user interface overlay for displaying and interacting with a map.

The MapOverlay class manages visual and interactive components of the map overlay, providing methods for initialization, input handling, and rendering.

Renders the map overlay, including the background, map nodes, connections, and the position of the train, based on the state of the world and its components.

This method is called when the control needs to be redrawn. It calculates the graphical representation of the map and its elements, applying scaling and positioning transformations to fit the UI overlay.
