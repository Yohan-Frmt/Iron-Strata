Detailed Description

Represents a turret component that can be attached to an entity in the world.

This component defines the fundamental properties of a turret, such as its attack range, damage it can inflict, rate of fire, and cooldown between attacks. These properties are utilized by systems like TurretSystem and DebugRenderSystem.
