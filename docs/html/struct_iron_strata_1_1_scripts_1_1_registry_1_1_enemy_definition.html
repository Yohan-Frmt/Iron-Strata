Detailed Description

Data structure defining base statistics and visual properties for an enemy type.

This structure groups all information necessary for creating and defining the behavior of an enemy, including its combat characteristics, movement, and visual appearance.

Parameters
typeThe unique identifier for the enemy type defined by the EnemyType enum.
damageThe amount of damage dealt by each successful attack.
attackRangeThe maximum distance (in Godot units) at which the enemy can attack.
attackSpeedThe attack rate expressed in attacks per second.
speedThe movement speed of the enemy in units per second.
healthThe maximum health points the enemy has when spawned.
scaleThe scale factor applied to the enemy's 3D model.
tintThe color tint applied to the model's material.
labelThe display name of the enemy, used for UI or debugging.
modelPathThe path to the 3D mesh resource to load.
dispersionRadiusThe dispersion radius used during group spawning to prevent overlap.
isFlyingIndicates whether the enemy can fly, affecting navigation and interactions.
